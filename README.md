# tripways-backend

Minimal Supabase foundation for building the Tripways global travel graph one feature at a time.

## Architecture

- `supabase/sql_src/schema`: one SQL file per schema or table, grouped by PostgreSQL schema.
- `supabase/sql_src/functions`: one PostgreSQL function per SQL file, grouped by feature.
- `supabase/functions/v1`: Edge Functions grouped by feature and operation.
- `supabase/migrations`: immutable deployment history generated by Supabase CLI.

## Local prerequisites

- Node.js 24+ and pnpm 11+ for repository commands
- Supabase CLI 2.95+
- Docker Desktop
- Deno 2.7+

## Setup

```bash
pnpm install
pnpm supabase:start
pnpm supabase:reset
pnpm verify
```

The Edge runtime is enabled for the authenticated user feature. If the local runtime cannot boot,
verify that Docker can reach JSR and npm package registries before debugging function code; the
runtime image resolves its own dependencies during startup.

The current implementation intentionally contains no Tripways domain tables. The next feature can
add one table and its behavior at a time. See `docs/brd/tripways-backend-foundation-brd.md` for the
long-term product direction. Remote linking and deployment remain outside this setup.
